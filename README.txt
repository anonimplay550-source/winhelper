1. ЧТО ЭТО ТАКОЕ
--------------------------------------------------------------------------------

WinHelper Ultimate — программа для оптимизации, мониторинга и обслуживания
Windows. Включает:

  • Мониторинг CPU / RAM / дисков / сети / батареи в реальном времени
  • Очистка кэша браузеров, приложений и Windows
  • Оптимизация питания, реестра и служб
  • Управление автозагрузкой, службами, задачами планировщика
  • Просмотр журнала событий, SMART-данных дисков
  • Менеджер установки приложений через winget
  • Инструменты безопасности (проверка брандмауэра, антивируса, UAC)
  • Утилиты: шреддер файлов, хеширование, архивация, бэкапы
  • Тёмная/светлая тема, 6 цветовых пресетов, 2 языка (RU/EN)
  • Анимации, живой фон, command palette (Ctrl+P)
  • Секретный DEV-режим с продвинутыми оптимизациями (7 кликов по версии)


--------------------------------------------------------------------------------
2. ЧТО НУЖНО ДЛЯ ЗАПУСКА
--------------------------------------------------------------------------------

Минимальные требования:

  • Windows 10 (1809) или Windows 11
  • Python 3.10 или новее — только если запускаешь winhelper.py напрямую
  • 200 МБ свободного места
  • Права администратора — для некоторых функций (очистка системных папок,
    служб, реестра HKLM, DISM, sfc, powercfg)


--------------------------------------------------------------------------------
3. БЫСТРЫЙ СТАРТ (ДЛЯ СЕБЯ)
--------------------------------------------------------------------------------

Если хочешь просто запустить программу у себя:

  Вариант A — напрямую из Python:

    1. Установи Python 3.10+ с https://www.python.org/downloads/
       При установке обязательно поставь галочку "Add Python to PATH".

    2. Открой командную строку в папке с проектом.

    3. Установи зависимости:

         pip install psutil

    4. Запусти:

         python winhelper.py

  Вариант B — установить как обычную программу:

    1. Запусти installer.py двойным кликом или командой:

         python installer.py

    2. Следуй инструкциям мастера: выбери папку, ярлыки.
    3. Готово — WinHelper в списке установленных программ и в меню Пуск.


--------------------------------------------------------------------------------
4. СБОРКА УСТАНОВЩИКА (ДЛЯ РАЗДАЧИ ДРУГИМ)
--------------------------------------------------------------------------------

Если хочешь получить один WinHelper_Setup.exe, который можно скинуть кому-то
и он просто поставит программу без Python и без pip:

    1. Установи Python 3.10+ с галочкой "Add Python to PATH".

    2. Положи все файлы проекта в одну папку:

         WinHelper/
           ├── winhelper.py
           ├── installer.py
           ├── uninstall.py
           └── build.bat

    3. Запусти build.bat двойным кликом.

    4. Дождись окончания сборки. Появится папка dist с двумя файлами:

         dist/WinHelper.exe         — сама программа (можно запускать)
         dist/WinHelper_Setup.exe   — установщик (это и раздавай)

    5. WinHelper_Setup.exe весит ~20-25 МБ, содержит внутри себя программу
       и удалятор. При запуске у получателя выглядит как нормальный установщик:
       приветствие, выбор папки, прогресс-бар со скоростью и ETA, ярлыки.

    6. На чужом компьютере Python не нужен — всё уже упаковано.


--------------------------------------------------------------------------------
5. ЧТО ДЕЛАЕТ УСТАНОВЩИК
--------------------------------------------------------------------------------

  ✓ Показывает окно приветствия
  ✓ Даёт выбрать папку установки (по умолчанию %LOCALAPPDATA%\WinHelper)
  ✓ Опции:
        [x] Ярлык на Рабочем столе
        [x] Ярлык в меню Пуск
        [ ] Запуск при входе в Windows (автозагрузка)
        [x] Запустить после установки
  ✓ Показывает прогресс-бар со скоростью (MB/s), оставшимся временем и
    списком устанавливаемых файлов — в стиле торрент-загрузки
  ✓ Копирует программу, создаёт ярлыки, прописывает запись в реестре
  ✓ Даёт запустить WinHelper сразу после установки

  Установка НЕ трогает системные файлы Windows. Всё происходит только в
  пользовательской папке и в ветке реестра HKEY_CURRENT_USER.


--------------------------------------------------------------------------------
6. КАК УДАЛИТЬ ПРОГРАММУ
--------------------------------------------------------------------------------

  Способ 1 — через Windows:

    Параметры → Приложения → Установленные приложения → найди WinHelper →
    Удалить

  Способ 2 — вручную:

    Запусти uninstall.py из папки установки.

  Что удаляется:

    • Сама программа
    • Ярлыки (Рабочий стол, Пуск)
    • Запись в реестре
    • Автозагрузка (если была включена)
    • Папка установки

  Что НЕ удаляется:

    • Файл настроек в %APPDATA%\WinHelper\wh_settings.json — если хочешь
      сбросить всё, удали эту папку вручную.

7. ВОЗМОЖНЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------

Проблема: Антивирус ругается на WinHelper_Setup.exe
Причина:  Файл собран через PyInstaller и не имеет цифровой подписи.
Решение:  Добавь файл в исключения антивируса, либо подпиши его
          сертификатом через signtool (требует платный сертификат).

Проблема: Ошибка "No module named 'psutil'" при запуске .py-версии
Решение:  pip install psutil

Проблема: Некоторые кнопки (DISM, SFC, powercfg) не работают
Причина:  Нужны права администратора.
Решение:  Запусти WinHelper от имени администратора
          (ПКМ по ярлыку → Запустить от имени администратора).

Проблема: Установщик не находит winhelper.py или WinHelper.exe
Решение:  Убедись, что файлы лежат в одной папке с installer.py.
          Если собираешь .exe — проверь, что build.bat добавил их через
          --add-data.

Проблема: Двойной статус-бар внизу окна
Решение:  Это баг старой версии. В текущей версии 4.6 исправлено:
          статус-бар пересоздаётся, а не добавляется поверх старого.

Проблема: Смена темы или языка выкидывает на страницу Настройки
Решение:  В версии 4.6 исправлено — программа возвращается на ту же
          страницу, где ты был.

Проблема: Живой фон с частицами не виден
Решение:  В версии 4.6 он показывается баннером сверху на Главной.
          Если всё равно не видно — проверь, что включены:
          Настройки → Анимации → Вкл, Живой фон → Вкл.

Проблема: Горячая клавиша "?" открывается при вводе пароля
Решение:  В версии 4.6 "?" игнорируется, если курсор в поле ввода.

8. СТРУКТУРА ФАЙЛОВ
--------------------------------------------------------------------------------

  winhelper.py       Основной код программы. Всё в одном файле.
  installer.py       Установщик. Собирается в WinHelper_Setup.exe.
  uninstall.py       Деинсталлятор. Копируется в папку установки.
  build.bat          Скрипт сборки обоих .exe через PyInstaller.
  requirements.txt   Список зависимостей (psutil, pyinstaller).
  README.txt         Этот файл.

  После сборки появятся папки:

  build/             Временные файлы PyInstaller (можно удалить).
  dist/              Готовые .exe:
                       dist/WinHelper.exe
                       dist/WinHelper_Setup.exe
  *.spec             Автоматически созданные конфиги PyInstaller.
                     Нужны только для повторной сборки.

  После установки на ПК пользователя:

  %LOCALAPPDATA%\WinHelper\
      WinHelper.exe  или  winhelper.py + WinHelper.bat
      uninstall.py

  %APPDATA%\WinHelper\
      wh_settings.json       Настройки программы
      Backups\               Резервные копии настроек

9. АВТОРУ И ЛИЦЕНЗИЯ
--------------------------------------------------------------------------------

Проект распространяется «как есть». Используй на свой риск.
Автор не несёт ответственности за любой ущерб от использования
программы, включая, но не ограничиваясь: потерю данных, повреждение
системы, неправильные оптимизации.

Все изменения в реестр делаются в HKCU (текущий пользователь) и в HKLM
(для системных твиков). Точки восстановления Windows можно создать
из раздела «Система» перед экспериментами.

Если что-то сломалось — сначала создай точку восстановления в
разделе «Система → Создать точку восстановления».
